# Text to Speech Converter

A simple Python application that converts text into speech using Google Text-to-Speech (gTTS).

## Features

- Text to speech conversion
- Supports English, Hindi, Telugu and Tamil
- Generates MP3 audio
- Runs in Google Colab
- Beginner-friendly Python project

## Technologies Used

- Python
- Google Colab
- gTTS

## Installation

```bash
pip install gTTS
